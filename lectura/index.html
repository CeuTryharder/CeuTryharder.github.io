Proyectos

DEW

Un asistente para el hogar. Tus datos, bajo tu control.

El inventario, las compras y los dispositivos del hogar suelen vivir en herramientas separadas. Conectarlos exige conservar el contexto sin perder el control de los datos ni de las acciones.

DEW reúne inventario doméstico, planificación de menús y compras, memoria con consentimiento y flujos de domótica. Un núcleo determinista en Python coordina las reglas del hogar; la arquitectura incorpora módulos Android en Kotlin y puentes hacia llama.cpp y sherpa-onnx para la ejecución local.

Python / Kotlin / llama.cpp / SQLite / Home Assistant

Límites documentados
  • La grabación muestra el simulador web conectado a dew_core con datos de demostración; no acredita una ejecución completa en un teléfono físico.
  • Las cifras de latencia, RAM e inferencia que aparecen en el panel del vídeo son anotaciones del grabador, no mediciones verificadas para este portfolio.
  • Los trámites se preparan con listas y enlaces oficiales; no se presentan ni firman automáticamente. Las acciones sensibles requieren confirmación.
  • La compatibilidad de modelos, voz y dispositivos domóticos debe validarse en el hardware y la red local de destino.

Automation Lab Starter

Del documento al resultado. RPA que se puede seguir paso a paso.

Automatizar un proceso exige algo más que resolver el caso correcto: hay que detectar datos incompletos, controlar duplicados, gestionar excepciones y dejar una traza que permita revisar cada decisión.

Cuatro laboratorios combinan workflows de UiPath Studio con motores deterministas en Python, puentes PowerShell y bases SQLite de demostración. Cada caso recorre entradas, reglas, persistencia y revisión humana. Las grabaciones muestran los documentos de partida, Studio y los resultados; el laboratorio de licitaciones incorpora UI Automation sobre una aplicación de escritorio local.

UiPath Studio / Python / PowerShell / SQLite / OCR local

Límites documentados
  • Los documentos, clientes, tickets, vehículos y expedientes son sintéticos. ERP, CRM, ITSM y portal de contratación son entornos locales de demostración.
  • Document Understanding cloud, colas de Orchestrator, Qdrant y conexiones a sistemas comerciales o portales oficiales siguen pendientes de integración.
  • Los vídeos editan las etapas y resultados de las ejecuciones documentadas; su duración no mide ahorro humano ni retorno económico.
  • Las acciones sensibles y propuestas requieren revisión. Los laboratorios no pagan facturas, envían ofertas, desbloquean cuentas ni presentan licitaciones.

Cesta Clara

Tu lista de la compra. Una comparación con criterio.

Comparar una lista de la compra exige respetar cantidades, marcas, formatos y costes de envío. Un precio aislado no cuenta toda la historia.

Una extensión de Chrome interpreta la lista mediante reglas locales y compara productos compatibles entre supermercados españoles. El mismo motor se ofrece a agentes mediante MCP, sin llamadas a modelos remotos para interpretar o calcular.

JavaScript / Chrome Extension / MCP / Reglas locales

Límites documentados
  • La cobertura y el precio local deben confirmarse en la tienda. Una consulta bloqueada o parcial no significa que el producto no exista.
  • La muestra incluida es histórica. Los precios de más de 24 horas, condicionados o caducados no completan una cesta.
  • Si faltan datos o los rangos se solapan, no se declara un ganador. Lidl y ALDI aportan precios de tienda física, sin cesta online compatible.
  • Puede preparar cantidades en carritos compatibles; nunca confirma ni paga pedidos. El dictado depende del navegador y puede enviar audio por Internet.

OllamaNotch

Una señal discreta para saber qué está haciendo tu modelo local.

El estado de un modelo local no siempre es visible mientras trabajas en otras aplicaciones.

Una utilidad de la barra de menús de macOS muestra estados de Ollama cerca del notch: desconectado, en espera, procesando y escribiendo. Consulta la API local de Ollama.

Python / rumps / Ollama / macOS

Límites documentados
  • Requiere macOS 12 o posterior, Python y Ollama instalado.
  • La detección de actividad usa heurísticas de VRAM y puede no ser precisa en configuraciones que usan CPU.

GalaxyBridge

Explorar el puente entre iPhone y Wear OS, empezando por la evidencia.

Los protocolos de sincronización de Galaxy Watch Ultra no se ofrecen como APIs públicas de iOS.

Una base experimental en Swift para descubrir dispositivos Bluetooth, gestionar conexiones e inventariar servicios GATT. Incluye un transporte simulado y diagnósticos limitados.

Swift / Core Bluetooth / iOS / GATT

Límites documentados
  • Todavía no empareja ni sincroniza un Galaxy Watch Ultra.
  • No ofrece sincronización de salud, llamadas ni notificaciones. La exploración Bluetooth requiere hardware físico.
